# 🛋️ Интернет-магазин мебели

Это учебный проект интернет-магазина мебели, реализованный с использованием HTML5, CSS3 и адаптивного дизайна. Проект поддерживает разные устройства: от настольных компьютеров до мобильных телефонов.

## 📌 Описание

Магазин включает в себя следующие страницы:

- **Главная страница** — представление бренда, каталог товаров и разделы по категориям.
- **Каталог товаров** — список продукции с фильтрами, изображениями, ценами и возможностью добавления в корзину.
- **Корзина** — просмотр выбранных товаров, изменение количества, удаление и оформление заказа.

## 🧰 Используемые технологии

- **HTML5**
- **CSS3 (с использованием Flexbox, Grid Layout)**
- **Google Fonts** (Montserrat)
- **Адаптивная верстка** под все типы устройств
- **Формы** для оформления заказа и подписки на обновления

## 📁 Структура проекта

```
project/

├── index.html            # Главная страница
├── catalog.html          # Каталог товаров
├── cart.html             # Корзина

│   └── style.css         # Основной CSS файл
```

## 🖥️ Как запустить проект локально

1. Склонируйте репозиторий:
```bash
git clone https://github.com/ваше-имя/интернет-магазин-мебели.git
```

2. Перейдите в папку проекта:
```bash
cd интернет-магазин-мебели
```

3. Откройте нужный HTML-файл в браузере:
```bash
index.html     # Главная страница
catalog.html   # Каталог
cart.html      # Корзина
```

## 📱 Адаптивность

Проект оптимизирован под разные экраны:
- Полная поддержка десктопных, планшетных и мобильных устройств.
- Удобное меню навигации и кнопки для тач-устройств.
- Медиа-запросы в CSS обеспечивают корректное отображение на всех размерах экранов.
